Auteur : Lokinas Peter Lemire
Date : Janvier-Aout 2024
Description : Projet de fin d'étude. Ce projet de recherche nous demandait de trouver un besoin d'usager et de developer la solution logiciel pour le combler. Le plan de projet initial délimite la porté du projet, les attentes à combler et les tâches nécessaires à sa completion. La modélisation utilise la représentation UML pour décrire l'architecture du projet à travers les différentes étapes. Le rapport de recherche final décrit la revue de littérature, la réalisation du projet, et l'analyse des résultats obtenus lors de son évaluation.
